Organization

四大中心，三条业务线

顶级旅游公司的效率来自中台复用；最常缺失的是"分离"。 我们把产品与交付、销售与交付彻底分开。

Center 01

产品与知识中心

线路立项、踩线、12 章手册、8 项风险实测、供应商库与知识库维护。 对知识资产负责，不对短期销售负责。

Center 02

交付与安全中心

出团质量、救援网络、医疗点、卫星通信、24h 值班台、车队与装备中心、领队管理。 有权叫停行程，且不因叫停而受绩效惩罚。

Center 03

市场与增长中心

品牌、内容支柱、影像资产库、数字投放、专属顾问制销售、社群与会员、B2B 渠道。

Center 04

组织与财务中心

人力与培训、领队认证管理、财务税务合规、集中采购与议价、合同与知识产权。

三条分离原则： 产品与交付分离——产品中心不为短期销量妥协手册； 销售与交付分离——销售 KPI 不含"交付满意度"，交付 KPI 不含"销售额"； 价格与交付分离——旺季不降价，用增值权益而非折扣成交。

Certification

四级领队认证

我们的核心壁垒。招的不是执行力强的螺丝钉，是能独立解决模糊问题的人—— 必须有真实长途驾驶与带队经历，并且能讲清一次失败。

级别准入培训考核可带线路
L1
助理领队		 领队证或 1 年领队经验 车辆与装备、基础急救、客户沟通、拍摄基础 笔试 + 随团观察 入门线（2 天）
L2
领队		 L1 + 3 团带队 高原生理、复杂地形驾驶、团队危机处理、物资工程 带队评估 + 模拟事故演练 主力线（5–7 天）
L3
高级领队		 L2 + 8 团 + 1 次高原 / 越野专项 复杂后勤、极端天气决策、领队带领队 事故复盘主笔 + 专项考核 旗舰线（8–15 天）
L4
首席领队		 L3 + 20 团 产品设计、供应商谈判、内容策划 手册主笔 + 内训授课 全部 + 带教 L1–L2

复训与红线

  • 全员每半年 2 天复训：高原急救、天气决策、新装备、案例复盘
  • 未参加复训者降级停岗，直至补训完成
  • 连续 2 次满意度 < 4.3 → 暂停带队
  • 作为 P1/P2 事件责任人 → 暂停带队并完成复评

薪酬设计

  • 底薪保障稳定 + 团费体现劳动量 + 评分奖金体现质量
  • 评分 < 4.3 的领队当月不参与评分奖金，并进入复训
  • 领队奖金与销售额不挂钩，只与安全与满意度挂钩
  • 有权中止行程的决定，不受绩效惩罚
Decision thresholds

继续还是撤退，用数字决定

领队不靠"感觉"。每个阈值对应一个不讨论的动作，写在每份手册里， 领队不得以客户意愿推翻阈值——除非客户主动要求并签署自愿承担确认。

情形阈值动作
降雨6 小时预报 > 25 mm，或山洪 / 地质灾害橙色及以上预警取消山区、峡谷、溪流边路段，启用备选
风力垭口 / 观景台阵风 ≥ 8 级放弃垭口，转向低海拔备选
能见度盘山路段 < 50 m停止前进，就地避险至服务区
气温夜间 < −15 °C 且无暖风可用取消露营，改住
路面结冰 / 积雪预警全线转城市或平原备选
道路管制官方封路 / 管制 / 景区关闭无条件改线；不可抗力全额退改
高反指标静息血氧 < 85% 观察；< 80% 立即处置；伴症状即下撤下降 500–1,000 m，持续给氧，必要时送医
车辆关键故障（转向 / 制动 / 轮胎）终止行程，启用备用车与租车白名单

每条线路另配 3 条备选路线卡，每条注明触发条件、改线后的里程与风景降级程度、 住宿餐饮安排，以及费用差异由谁承担。

Quality

四层质检与无责复盘

复盘不问"谁的错"，只问"下次怎么避免"。这是组织学习能持续的唯一前提。

层级时机执行产出
L1 产品验收上线前12 章手册齐全 + 踩线 ≥ 3 次 + 供应商协议齐备上线批准
L2 出行前T-1车辆检查表、天气复核、名单与证件、物资按布局图装箱出行放行单
L3 神秘客每线每季 1 团未参与该团的产品经理随团，按 12 章逐项打分质检报告
L4 复盘每团后 + 每季问卷、投诉、事件、成本偏差、领队自评、供应商表现复盘报告 → 手册更新
指标

满意度 ≥ 4.7

< 4.3 触发该领队暂停带团与复训。

红线

安全事故 = 0

1 起 P1 事件即全公司停业复盘，不作个案处理。

指标

准时率 ≥ 92%

按手册行程时间考核，含集合、到达与用餐节点。

指标

成本偏差 ≤ 105%

连续 2 个月 > 115% 的线路必须调价或下线。

Workflows

三条业务线的流程

C 端线（散客与定制）

内容获客 → 私域沉淀

搜索与内容触达 → 加微信 → 进团友社群体系。

专属顾问咨询

15 分钟内首次响应，主动给出两个方案而非等客户问。

签约与定金

签约付 30%，出发前 15 天付至 70%，出发前 3 天结清。

成团与放行

T-7 成团确认 → T-3 复核 → T-2 说明会 → T-1 车检放行。

出团与复盘

每日平安确认 + 每日评分 → T+5 成片交付 → 邀评 → 会员与转介绍。

B2B 线（地面执行）

伙伴签约

提供手册、报价口径与接待标准，形成双合同、双保险、双 SOP。

行程定制与报价

地面成本 + 服务费 12–15% + 风险准备金 3%。

地面执行

我方领队 + 供应商交付，全程按我方标准质检。

服务报告与结算

T+30 结算，含服务质量报告与问题清单。

企业与品牌线

需求共创

明确目标：产品验证 / 内容传播 / 品牌形象 / 团队建设。

可行性与预算

预算、时间窗口与安全边界三方校验。

方案与合同

含技术方案（车辆改装 / 摄影 / 供电 / 通信）与变更条款。

试运行 → 正式执行

小规模走一遍验证流程再放大。

交付与复盘

内容交付 + 服务报告 + 复盘 + 年度框架合作洽谈。
